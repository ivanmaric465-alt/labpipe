# Conventions of this lab

Instructions for all agents of this project, whatever their role. They are added to the end
of the generated `AGENTS.md` and `CLAUDE.md`. Write plain sentences; delete these examples.

- We call the support "Vulcan"; "the old batch" means samples S-1 to S-8.
- Answer in the language the user writes in.
- Names of our samples: S-<number>, with a letter for a repeat (S-9b).

To add something for one role only (e.g. `xrd-analyst`), see `lab/agents/README.md`.
After editing this file, run `labpipe project sync`.
