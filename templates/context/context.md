# Project context

Written by you (or by the agent with you). The postdoc reads this before the data.
Keep it short and plain; update it when the project changes.

## Project aims
What is this project trying to find out or make? One short paragraph.

## Hypotheses
What do you expect, and why? One line each.

## Samples and what they should show
One line per sample or series, e.g. "S-9: reference, should show only the base phase".
Nominal compositions and preparation details belong here if they matter.

## What matters
What would count as a good result? Which comparisons or numbers decide things?

## Open questions
What is unclear, suspicious or not measured yet?
