# Instructions for the postdoc

Edit this file freely. It steers what the postdoc reads and how it weighs things.
It cannot loosen the rules in AGENTS.md (no invented numbers, raw data read-only,
review checks always mentioned).

## What to read
- `context.md` describes the project now. If it disagrees with an older document, `context.md` wins.
- `documents/`: the work plan defines the aims; papers are for background and reference
  values only. Cite the file and page (`documents/paper.pdf p. 6`).
- Add one line per document here saying what it is for, e.g.
  "documents/work-plan.pdf: the aims and the sample list".

## Priorities
- Answer the question asked first; then say what else you noticed.
- Prefer comparisons across samples and methods over repeating single-measurement notes.

## Suggested structure
After the required parts (Question, Summary, Check before using):
- Observations
- Insights and ideas
- Suggested next steps

## Language
Write in English.
